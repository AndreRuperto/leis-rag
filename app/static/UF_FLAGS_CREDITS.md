# Bandeiras das unidades federativas

As 27 bandeiras (26 estados e Distrito Federal) utilizadas pelo dropdown **UF**
foram obtidas de:

- **Autor/origem:** Pierre Lapalu — [Ícones de Bandeiras de Estados do Brasil](https://github.com/pierrelapalu/icones-bandeiras-br-uf)
- **Licença informada pelo projeto:** Creative Commons CC0 1.0 Universal
- **Arquivos de origem:** `dist/rounded/svg/`, utilizando versões `-v2` de Ceará, Espírito Santo e Paraíba.
- **Integração:** `uf-flags-1.js`, `uf-flags-2.js`, `uf-flags-3.js` contêm cópias SVG locais, carregadas como imagens; não é necessária requisição de bandeiras a sites externos.

Os códigos das UFs e os nomes são exibidos junto à bandeira. O código escolhido
é enviado como filtro (`uf`) sem alteração da API existente.

Este projeto não reivindica autoria das bandeiras e não associa a imagem à
validade ou vigência de qualquer lei.
